01 · Decode shipping

A pull request description. Nothing looks wrong.

Tag-block characters (U+E0000 to U+E007F) render as nothing in every editor, diff view and review UI. A model tokenizes them anyway. Press Decode, or paste your own text.

02 · Two engines planned

      
One would read the workflow. One would read the repo.

      
Neither engine is built. The transcripts below are illustrations of the output being designed, not recordings of a program that runs.

    


    

      

        
config planned

        
Static taint analysis of GitHub Actions. Untrusted input, such as pull request titles, issue bodies and comments, traced to an agent step that holds a write token. Deterministic, with no model in the loop.

        
$ promptdecode scan --engine config .github/workflows/

        source  github.event.pull_request.title     L14

        token   permissions.pull-requests: write    L6

03 · Install planned

      
Three lines, when there is something to install.

      
The Action is designed and unwritten. promptdecode/action@v1 does not resolve today, so the snippet is shown rather than offered for copying: pasting it into a workflow would fail the run.

      
The intent it records: findings post as check annotations on the pull request. No account, no token exchange, and nothing leaving the runner.

    

    

      
.github/workflows/ci.ymlplanned

      
- uses: promptdecode/action@v1
  with:
    engines: config, content

    

  






  

    
04 · What we claim, and what we don't

    

      
We do not publish a percentage of attacks blocked.

      
Published evasion rates against commercial detectors swing wildly with the technique used. A number that moves that much is not a number, and we will not print one to make a point.

      
Two things are worth publishing instead. Deterministic coverage of named Unicode classes: every code point in a listed range is found, every time. And recall at a stated false-positive rate on a named corpus, with the corpus and the harness in the open.

      
If a class is not on the list, we do not detect it. The list is the claim.

      
Today the list is short and the whole of it is above: tag block, bidi overrides, variation selectors, decoded in your browser. The benchmark that would carry the rest is not written.
